# crformats 0.1.0

* `pkg_user_dir()` returns a platform-specific user directory for an R package.

* `ls_format()` and `use_format()` replace `ls_ext()` and
  `use_quarto_ext()`.

* `use_docx_template()` and `ls_docx()` have been removed; docx formats are
  now supplied as Quarto extensions.

* Initial CRAN submission.
